# 边界与已论定（防止已定裁定被当新缺陷重报）

AI 在长期使用中会反复遇到同样的问题。本文件记录**已经想清楚的决定**，
每行带「重议条件」—— 满足条件才重新讨论，否则按既有结论处理。

---

## 不适用 / 不做的（已论定）

| 事项 | 结论 | 理由 | 重议条件 |
|------|------|------|---------|
| 在仓内保留 OpenClash 官方知识副本 | **不做** | 官方文档持续更新，本地副本必然过期；引用 URL 更正确 | 官方文档消失或不再可访问 |
| 内置内核模块黑名单（禁用无用 WiFi/GPU 模块省内存） | **不做** | 收益小（实测约 12MB）但风险高（可能禁掉在用的驱动）；且需维护黑名单随内核版本更新 | 用户明确要求且能承受重启风险 |
| 自动检测并卸载 iStoreOS 组件 | **不做** | `quickstart`/`linkease` 有隐藏依赖（首页/商店），误删代价大。改为「先出表格给用户看」 | — |
| 把 `oc.py` 拆成多个文件 | **不做** | 单文件便于作为「黑盒脚本」分发和调用；拆分增加 agent 的路径认知负担 | 超过 2000 行，或需要独立复用某模块 |
| 打包成 pip 包分发 | **不做** | 技能标准要求自包含目录 + `SKILL.md`；pip 安装会绕开技能发现机制 | Agent Skills 标准改变 |
| `name` 字段用大写（`OpenClash-Router`） | **不做** | 规范硬性要求小写；大写会导致某些实现拒绝加载 | 规范放宽 |

## 例外清单

| 情形 | 处理 |
|------|------|
| 用户明确要求「只改运行配置」 | 可以，但**必须**同时说明重启后会丢失，并建议改用源文件 |
| 用户明确要求明文存密码（`setup --no-key`） | 可以，但要提示风险；不得主动推荐 |
| 路由器不是 OpenWrt 系（如标准 Linux） | 部分命令可能不适用（`uci`/`apk`），先确认环境再动手 |

## 反复出现的误解（写下来省得再解释）

**Q: 为什么仓库名是 `OpenClash-Router` 但 `name` 字段是 `openclash-router`？**
A: 仓库名给人看，`name` 给机器看。Agent Skills 规范要求 `name` 只能是
`[a-z0-9-]`。README 里有说明，不是笔误。

**Q: 为什么 Google Play 的覆写文件被删了？**
A: 实测证明在 Fake-IP 模式下它本来就是多余的（`services.googleapis.cn`
已被 `google` 规则集收录，走代理正常）。详见 `pitfalls.md` 的相关复盘。
仅当用户切到 redir-host 模式 + 开大陆绕行时才需要它。

**Q: 为什么技能里没有 OpenClash 的选项说明？**
A: 故意的。领域知识引用官方文档（会更新），技能只管操作流程。
见 `SKILL.md` §1。
